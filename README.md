# 🧑‍💼 HR Analytics Dashboard — Power BI

## 📌 Project Overview
An interactive HR Analytics Dashboard built in Power BI that analyzes
employee attrition, salary trends, department strength, and workforce
demographics to help HR teams make data-driven decisions.

---

## 📊 Key Metrics
| Metric              | Value  |
|---------------------|--------|
| Total Employees     | 1,403  |
| Active Employees    | 1,195  |
| Attrition Count     | 208    |
| Attrition Rate      | 15%    |
| Average Age         | 37.67  |
| Avg Experience      | 7.26 Years |

---

## 🔍 Dashboard Features
- ✅ Attrition by Department, Salary Slab & Gender
- ✅ Age Group Distribution
- ✅ Attrition by Job Role & Job Satisfaction Matrix
- ✅ Attrition Trend by Experience (Years)
- ✅ Department-wise Employee Count
- ✅ Dynamic Age Group Slicer (18-25, 26-35, 36-45, 46-55, 55+)

---

## 💡 Key Insights
- Employees in lower salary bands (0–6 LPA) show the highest attrition
- Laboratory Technicians have the highest attrition count (52) among all roles
- Attrition spikes at specific experience milestones suggesting career inflection points
- Males (65.38%) account for higher attrition compared to females (34.62%)
